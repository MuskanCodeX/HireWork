================================================================================
                    HIREWORK FREELANCE MARKETPLACE
                 STEP-BY-STEP QUICK START & RUN GUIDE
================================================================================

PREREQUISITES:
1. Node.js (v18.0.0 or higher, v20+ recommended) -> https://nodejs.org/
2. MongoDB installed locally OR free MongoDB Atlas cloud cluster -> https://www.mongodb.com/

--------------------------------------------------------------------------------
STEP 1: OPEN TERMINAL IN THIS FOLDER
--------------------------------------------------------------------------------
Open PowerShell, Command Prompt, or Terminal in this folder:
cd hirework-freelance-marketplace

--------------------------------------------------------------------------------
STEP 2: CONFIGURE ENVIRONMENT FILES (.env)
--------------------------------------------------------------------------------
A) For the Backend:
   Copy "backend/.env.example" to "backend/.env":
   - Windows PowerShell: Copy-Item backend\.env.example backend\.env
   - Windows CMD:        copy backend\.env.example backend\.env
   - Mac/Linux:          cp backend/.env.example backend/.env

   Open "backend/.env" in any text editor and verify:
   PORT=5000
   NODE_ENV=development
   MONGO_URI=mongodb://localhost:27017/hirework
   JWT_SECRET=hirework_super_secure_jwt_secret_key_2026_xyz123
   CLIENT_URL=http://localhost:5173

   (If using MongoDB Atlas, paste your mongodb+srv://... connection string into MONGO_URI)

B) For the Frontend:
   Copy "frontend/.env.example" to "frontend/.env":
   - Windows PowerShell: Copy-Item frontend\.env.example frontend\.env
   - Windows CMD:        copy frontend\.env.example frontend\.env
   - Mac/Linux:          cp frontend/.env.example frontend/.env

   Default values are ready to use:
   VITE_API_URL=http://localhost:5000/api
   VITE_SOCKET_URL=http://localhost:5000

--------------------------------------------------------------------------------
STEP 3: INSTALL ALL DEPENDENCIES
--------------------------------------------------------------------------------
From this root folder, run:

npm run install:all

--------------------------------------------------------------------------------
STEP 4: SEED SAMPLE DATA (PROJECTS, USERS, GIGS)
--------------------------------------------------------------------------------
From this root folder, run:

npm run seed

This populates the database with verified users, open projects, and services.

--------------------------------------------------------------------------------
STEP 5: START THE APPLICATION
--------------------------------------------------------------------------------
To start both Backend and Frontend together with one command:

npm run dev

Or run in separate terminals:
- Terminal 1 (Backend API): npm run server   (Runs on http://localhost:5000)
- Terminal 2 (Frontend UI):  npm run client   (Runs on http://localhost:5173)

Open your browser at: http://localhost:5173

--------------------------------------------------------------------------------
